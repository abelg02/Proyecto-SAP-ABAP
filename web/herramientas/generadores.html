Generadores

Código que se repite en cada proyecto y que no aporta nada escribir a mano. Cambia los datos y el código se actualiza al momento. Todo se genera en tu navegador.

1. BO RAP · 2. Tipos desde JSON · 3. Report ALV · 4. Tests ABAP Unit · 5. Clase de excepción

1. Business Object RAP gestionado con draft

Escribe el prefijo y el nombre de la entidad. Obtienes tabla, vista raíz, proyección, metadata extension, parámetro de acción, BDEF, BDEF de proyección, behavior pool y service definition, con los nombres ya ajustados a las longitudes máximas de SAP.


        

        
Orden de creación en ADT y explicación de cada parte en la documentación del ABAP Toolkit. La tabla draft la genera ADT desde la BDEF (Ctrl+1).

      

    

  






  

    
2. Tipos ABAP desde JSON

    
Pega la respuesta de una API. Se generan las estructuras y tablas anidadas, con los nombres en snake_case para que /ui2/cl_json las rellene en modo camelCase, y el código para deserializar.

3. Report ALV completo

    
Para ECC y S/4HANA on-premise. Indica la tabla, los campos a mostrar y los que quieres como criterio de selección. Genera el report con clase local, SELECT con sintaxis moderna, ALV con funciones, columnas optimizadas, cebra y variantes guardables.

4. Esqueleto de tests ABAP Unit

    
Pega la definición de una clase (desde CLASS ... DEFINITION hasta ENDCLASS). Genera la clase de test local con un método de prueba por cada método público, la instancia de la clase en setup y la estructura Dado / Cuando / Entonces con los parámetros ya declarados.

5. Clase de excepción con mensajes T100

    
Una línea por mensaje con el formato constante;número;texto. Usa &1 a &4 para los valores variables. Genera la clase con IF_T100_DYN_MSG, una constante por mensaje, los atributos necesarios y la lista de mensajes que hay que crear en SE91.

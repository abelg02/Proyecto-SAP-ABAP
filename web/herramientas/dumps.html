Explicador de dumps ST22

Pega el texto del dump (o solo el nombre del error, como TIME_OUT). Te explica qué ha pasado, las causas más habituales, cómo analizarlo y cómo se corrige en código. Funciona con dumps en español y en inglés.

En la ST22, abre el dump y copia desde el principio hasta "Information on where terminated" / "Información sobre el lugar de terminación". El texto no sale de tu navegador.

Todos los errores

Los errores de ejecución más frecuentes en sistemas SAP, agrupados por tipo.

Cómo leer un dump sin perderse

  1. Runtime Error / Error tiempo de ejecución: el nombre del error. Es lo primero que hay que buscar.
  2. Exception / Excepción: si aparece una clase CX_..., el error se podría haber capturado con TRY ... CATCH.
  3. What happened / Qué ha sucedido y Error analysis / Análisis de errores: el detalle con valores concretos (la tabla, el campo, el valor que no se pudo convertir).
  4. Information on where terminated: programa, include y línea. Con doble clic en ST22 se abre el código en ese punto.
  5. Active calls / Llamadas activas: la pila. Lee de abajo arriba para ver el camino que llevó al error.
  6. Chosen variables / Variables seleccionadas: el valor de las variables en el momento del error. Muchas veces basta con esto.

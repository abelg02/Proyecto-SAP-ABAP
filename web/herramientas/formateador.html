Formateador de código ABAP

El Pretty Printer sin abrir el sistema: pega código copiado de un correo, de un ticket o de un documento y recupera la sangría por bloques y el estilo de las palabras clave. Útil también para revisar código en una wiki o en una pull request de abapGit.

Resultado

      

    

    
Reconoce IF/ELSEIF/ELSE, LOOP, DO, WHILE, CASE/WHEN, TRY/CATCH/CLEANUP, METHOD, FORM, FUNCTION, MODULE, CLASS con sus secciones, INTERFACE, AT NEW/END OF y SELECT ... ENDSELECT. Las líneas de continuación (WHERE, AND, parámetros) conservan su sangría relativa. Los comentarios con * se quedan en la columna 1, como en SAP.

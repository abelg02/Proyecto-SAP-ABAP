Ejemplo: log de aplicación en ABAP Cloud

Sin la clase, guardar un log con CL_BALI_LOG son unas quince líneas con tres clases distintas y un TRY por cada mensaje. Con la clase:

DATA(lo_log) = zcl_abk_log=>create( iv_object      = 'ZABK_LOG'
                                    iv_subobject   = 'IMPORT'
                                    iv_external_id = |Fichero { lv_name }| ).

lo_log->info( |Leídas { lines( lt_rows ) } filas| ).

LOOP AT lt_rows INTO DATA(ls_row) WHERE supplier IS INITIAL.
  lo_log->error( |Fila { sy-tabix }: proveedor vacío| ).
ENDLOOP.

lo_log->save( ).

Ejemplo: BAPI con control de errores

El error más habitual con BAPIs es hacer COMMIT aunque RETURN traiga un error. La clase decide por ti:

CALL FUNCTION 'BAPI_PO_CHANGE'
  EXPORTING purchaseorder = lv_ebeln
  TABLES    return        = lt_return
            poitem        = lt_item
            poitemx       = lt_itemx.

DATA(lo_result) = zcl_abk_bapi=>finish( lt_return ).

IF lo_result->is_ok( ).
  MESSAGE s001(zmm) WITH lv_ebeln.
ELSE.
  lo_log->add_bapiret2( lo_result->errors( ) ).
ENDIF.

Instalación con abapGit

  1. Crea un paquete local o transportable (por ejemplo ZABK_CLOUD).
  2. En abapGit (ADT en ABAP Cloud, report ZABAPGIT on-premise) elige New Offline, asigna el paquete e importa el ZIP.
  3. Pulsa Pull y activa los objetos.
  4. Crea los requisitos de las clases que vayas a usar (objeto de log, clase de mensajes, rango de números...). Están en la cabecera de cada clase.

Si prefieres no usar abapGit, abre el ZIP y copia cada fichero .abap en una clase con el mismo nombre.

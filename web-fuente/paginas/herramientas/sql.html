Conversor de Open SQL a sintaxis estricta

Pega tus SELECT antiguos y obtén la versión con sintaxis estricta: variables con @, campos separados por comas, FIELDS y el INTO al final. Es la sintaxis que exige ABAP Cloud y la que permite usar expresiones SQL. De paso, te avisa de lo que conviene revisar.

Sintaxis estricta (7.40 SP05+)

Cómo decide qué es una variable

En la sintaxis antigua, WHERE matnr = lv_matnr no indica si lv_matnr es una columna o una variable ABAP. El conversor añade @ cuando:

  • El nombre sigue las convenciones habituales: lv_, ls_, lt_, gv_, p_, s_, iv_, is_, wa_, it_, field-symbols y sy-.
  • Es un componente de estructura (ls_item-matnr) a la derecha de una comparación.
  • Es space, abap_true o abap_false.

Si encuentra un nombre que no sabe clasificar, lo deja como está y te avisa para que lo revises. Es preferible a equivocarse en silencio.

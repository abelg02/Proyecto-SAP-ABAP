# Serie gratuita: ABAP Cloud y RAP desde cero hasta tu primera app

Idea para una serie de vídeos gratuitos (YouTube o LinkedIn) que complementa la web. Cada vídeo de 8-15 minutos, con el código en abapGit.

**Para quién:** programadores de otros lenguajes, consultores funcionales que quieren pasar a desarrollo y desarrolladores ABAP clásicos que no han tocado RAP.

## Módulo 0 · Preparar el entorno
1. Qué es SAP, S/4HANA, BTP y dónde encaja ABAP hoy
2. Crear la cuenta trial de SAP BTP ABAP Environment
3. Instalar Eclipse + ADT y conectar
4. Primer programa: clase con `IF_OO_ADT_CLASSRUN`
5. abapGit: clonar los ejercicios

## Módulo 1 · El lenguaje
Tipos y declaraciones en línea · estructuras · condiciones y bucles · string templates · fechas en ABAP Cloud · ejercicio: días laborables

## Módulo 2 · Tablas internas
STANDARD, SORTED y HASHED · expresiones de tabla · VALUE, CORRESPONDING, COND, SWITCH · FOR, REDUCE, FILTER, GROUP BY · ejercicio: ventas por cliente

## Módulo 3 · Orientación a objetos
Clases, visibilidad, constructores · herencia, interfaces, polimorfismo · excepciones propias · ABAP Unit · ejercicio: cálculo de precios con tests

## Módulo 4 · Diccionario y ABAP SQL
Dominios, elementos de datos, tablas · SELECT con sintaxis estricta · JOIN, agregados, CASE · escribir en base de datos · rendimiento: el SELECT en el LOOP

## Módulo 5 · Core Data Services
Por qué existen · asociaciones y composiciones · anotaciones · value helps · access control

## Módulo 6 · RAP
Arquitectura · BDEF · determinaciones · validaciones con `%element` y `%state_area` · acciones con `features : instance` · autorizaciones · draft · EML · servicio OData V4 y Fiori Elements · tests de un BO

## Módulo 7 · Proyecto final
App de solicitudes con estados, aprobación, historial y avisos por email, de principio a fin.

## Módulo 8 · Clean core
ABAP Cloud en S/4HANA on-premise · cómo leer un informe del ATC · usar CleanCore Check para preparar una migración

## Producción
- Grabación con OBS Studio, pantalla a 1920x1080 y fuente de ADT a 14 pt.
- Cada vídeo: objetivo en una frase, demostración, ejercicio y solución en abapGit.
- Enlazar cada vídeo desde la herramienta o el artículo del blog relacionado.
